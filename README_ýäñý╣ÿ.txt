품질 비서 (개인용) – 설치 방법

1) GitHub에서 새 저장소를 만듭니다. 예: asistente-calidad  (불량 히트맵과 같은 계정이면 서버 연결이 자동으로 이어집니다)
2) 이 폴더의 파일을 모두 그 저장소 맨 위에 올립니다 (index.html, manifest.webmanifest, sw.js, icons 폴더).
3) Settings → Pages → Branch: main / (root) → Save.  1~2분 뒤 주소: https://<계정>.github.io/asistente-calidad/
4) 휴대폰에서 그 주소를 열고 설치
   - 안드로이드 크롬: 위쪽 '앱 설치' 버튼 (또는 메뉴 → 홈 화면에 추가)
   - 아이폰 사파리: 공유 → 홈 화면에 추가
5) 처음 한 번: ⚙ 설정
   - 서버 연결: 히트맵과 같은 계정이면 자동. 다른 계정이면 히트맵의 설정 링크(#cfg=…)를 붙여넣기
   - 사례집 엑셀 (품질대책_사례집_v1.7 이상 – 4M 신고기준·검사POINT 포함) 불러오기
   - Claude API 키 (선택 – 넣으면 앱 안에서 자문·대책서 초안)
6) VAATZ: 상단 VAATZ 버튼 → 엑셀·CSV 불러오기 (열 자동 매칭, 확인 후 저장) / 통보서 PDF·사진 → 대책서 초안

※ 사례집·VAATZ 자료·API 키는 이 기기 브라우저에만 저장되고 GitHub에는 올라가지 않습니다.
